# 新加速タイム

本日のレース場・レースを選ぶと、各レース場が独自に計測した
**展示・一周（桐生は半周）・まわり足・直線** と、そこから計算した **新加速タイム・エンジンパワー** を表示します。

## 使い方
- **Web版（GitHub Pages）**：GitHub Actions でデータを集めて公開します（定期実行は現在停止中。Actions 画面の「Run workflow」で手動実行できます）。
  各レースは締切の約90分前から締切30分後まで取り直します。GitHub の定期実行は混雑時に遅れることがあります。
- **Render版（その場で取得）**：`render.yaml` で Render の無料 Web サービスとして `server.py` を公開します。
  「更新」を押すと、その場で各レース場サイトから取得します。15分間アクセスがないと停止し、次のアクセスは起動に30〜60秒かかります。
- **保存**：6艇分のタイムがそろったレースは、サーバ（`cache/`）とブラウザに保存し、次からは取り直さずにすぐ表示します。
  レース場を選ぶと、締切30分前を過ぎた（展示済みの見込みの）レースをサーバが裏で1件ずつ取得して保存します。
  「更新」ボタンを押したときだけ取り直します（再展示などで値が変わったとき用）。保存は当日分のみです。
- **ローカル版**：`start.bat` をダブルクリック（または `python server.py`）→ http://localhost:8765/ 。
  開いたその場で各レース場のサイトから取得します。Python 3 の標準ライブラリだけで動きます。

## 新加速タイム（計算ロジック）
展示・まわり足・直線から、出足・中間速1〜3・伸び（km/h）とエンジンパワー（平均70）を計算します。
- 区間速度 ＝ 進入コースごとの定数 ÷ タイム。6艇平均との差に重みをかけて合計し、70を足したものがエンジンパワーです。
- 進入コースは公式サイトのスタート展示の並びを初期値にし、展示タイムの表の行を上下にドラッグして変更できます。
- 直線タイムがない場合は「直線＝展示タイム」として計算します。
- 「手入力で補正する」をオンにすると、タイムを手で入力・修正できます（685→6.85、3676→36.76）。
- 計算部分は index.html の `ACCEL` / `calcAccel` にあります。2024/2/22 琵琶湖 7R の計算例と一致することを確認済みです。
- 定数と重みは、琵琶湖の3レース分の表から推定した値です。

## 構成
- `index.html` … 画面（ローカルサーバがあれば API、無ければ `data/today.json` を読む）
- `scraper.py` … 各場サイトからの取得と表の解析（会場設定は `VENUES`）
- `server.py` … ローカルサーバ（`/api/venues`, `/api/race?jcd=&rno=`）
- `build_data.py` … Actions 用。本日の全レースを集めて静的サイト（`site/`）を作る
- `.github/workflows/update.yml` … 定期実行と GitHub Pages への公開

平和島・住之江・丸亀・児島のページは日付指定ができず、当日分のみ取得できます。

同じサイトへのアクセスは1件ずつ間隔をあけて行います。
